About This Contest

Comprehensive reference and training mashup for university competitive programmers.

Contest Structure

This contest is an organized Codeforces Gym Mashup created for SGU University students. Problems are meticulously organized in increasing difficulty from rating 800 up to 1100, providing an optimal learning curve for mastering competitive programming fundamentals.

Curated Topics

The problemset systematically covers fundamental competitive programming paradigms: Basic Conditions, Integer Arithmetic, Simulation Loops, 2D Arrays, String Processing, Sorting Algorithms, Combinatorial Math, and Grid Implementation.

Verified Java Solutions

All solutions are written in standard Java (JDK 8+ compatible), following best competitive programming practices: using public class Main, standard Scanner I/O, fast string buffering where required, and zero external dependencies.

Local Progress Tracking

Solve problems at your own pace! Mark problems as solved or unsolved; your progress is automatically saved to your browser's localStorage and persists across sessions and page reloads.
